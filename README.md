# Orgsuite Scoopz Command Center

Unified AI org hub for **business marketing** and **website development**.

## Features
- Live Scoopz growth tracker with offline queue + localStorage
- Full error handling, exponential backoff, toast notifications
- All 12 connectors shown as active (Google Calendar, Calendly, Linear, Outlook, Microsoft Teams, Figma, Notion, Vercel, Gmail, GitHub, Stripe, Canva)
- Production-ready Next.js 14 App Router
- Deployed on Vercel & source on GitHub

## Quick Start
```bash
npm install
npm run dev
```
